What Ballast is

Plain-text instructions your AI agent follows to find and clear what AI tools leave behind: chat transcripts, virtual machine images, caches, scratch projects and stray processes. Nothing to install. It never deletes personal files.

What this page is

If something is blocked

Locked files, administrator rights and denied permissions are common. The message you send tells your agent not to stop at "I can't". It must say what is blocking the item, ask you for the permission it needs, and show the workaround or the exact command you can run yourself.

The eight checks

Every item is checked before it gets a tier: when it was last used, whether it is in use right now, whether it is really an installed program, whether anything depends on it, whether it holds unsaved work, whether it is cloud-synced or shared, whether its name marks it as protected, and how to get it back. A check shows Good, Heads up, Blocker, Not checked or Not relevant.
